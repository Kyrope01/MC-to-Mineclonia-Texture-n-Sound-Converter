MC to VoxeLibre Converter

Drop a Minecraft texture-pack .zip — get a ready-to-use VoxeLibre (Luanti) texture pack

Output:
Loading default Minecraft texture download link…
Install the patch: extract mcl_sounds.zip into the folder for your system below, replacing the existing mcl_sounds files (merge → ~120 .ogg + init.lua), then restart your world.
Linux~/.minetest/games/voxelibre/mods/CORE/mcl_sounds/
Flatpak: ~/.var/app/org.luanti.luanti/.minetest/games/voxelibre/mods/CORE/mcl_sounds/
Windows%APPDATA%\Minetest\games\voxelibre\mods\CORE\mcl_sounds\
On servers you don't own, sounds always come from the server — that's engine-enforced (every file is hash-checked), no client-side pack can change it. To hear this multiplayer, install the patch on the host: your own server, or ask the admin of theirs.

Runs fully in your browser. Texture mapping: blocks, items, mobs, tools, armour, doors, beds, copper, torches… Luanti mod (enable per world): per-block place, break, mine and footstep sounds (deepslate, amethyst, sculk, mud… whenever the pack ships them). Game-files patch (no mod to enable): swaps stock sound files + appends a per-block block to mcl_sounds/init.lua — mod-like sounds in every world and on servers you host.
